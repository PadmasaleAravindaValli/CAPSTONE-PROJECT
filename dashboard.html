Pipeline 1: Chicago Incident Classification

Micro-Incident Triage

Dataset: Chicago Police Department (2023–2025), 756,085 records across 22 districts.
Task: Binary classification of domestic altercations (Domestic = 1/0).
Class Balance: 18.46% Domestic prevalence (minority class imbalance).
Temporal Split: Train (388k, 2023–24H1), Val (131k, 2024H2), Locked Test (236k, 2025).
Leakage Purge: Removed Description (contained "DOMESTIC" in 143k rows) and post-arrest flags.

Pipeline 2: Indian NCRB Crime Burden Forecasting

Macro-District Sequence

Dataset: National Crime Records Bureau (2001–2014), 9,856 district-years.
Task: 5-tier ordered violent crime burden category (TARGET_VIOLENT_LEVEL).
Thresholds: Frozen quintiles (107, 237, 362, 563) on 2001–2010 training data.
Sequence Design: 3-year consecutive lag window (t-3, t-2, t-1 → t).
Test Evaluation: Locked 2013–2014 cohort across 5 independent random seeds.

Dataset 1: Baseline (14 Features)

Strictly raw temporal, spatial, and nominal administrative features without domain engineering:

  • Temporal (4): Hour, Month, DayOfWeek, IsWeekend
  • Spatial (6): District, Beat, Ward, Community Area, Latitude, Longitude
  • Categorical (2): Primary Type, Location Description
  • Metadata (2): Date, split (train/val/test indicator)

Dataset 2: Enhanced (29 Features)

Augments Dataset 1 with 15 domain-engineered criminological features:

  • Trigonometric Cyclical (6): Hour_Sin/Cos, Month_Sin/Cos, DayOfWeek_Sin/Cos
  • Venue / Shift Flags (4): Is_Residential, Is_Public_Space, Is_Night, Time_Period
  • Bayesian Risk Priors (3): Primary_Type_Domestic_Risk, Location_Domestic_Risk, Beat_Domestic_Risk
  • Spatial Interaction (2): Beat_Historical_Incident_Volume, Type_Location_Interaction

⚠️ The NCRB Target Leakage Revelation

In legacy literature, an 80/20 random stratified split yielded an apparent 90.76% Accuracy. Forensic analysis revealed 9 input IPC columns directly summed into the violent crime burden target. When re-evaluated on genuine future-year forecasting using 3-year sequential history:

  • Random Stratified MLP (Leaked): 90.56% Accuracy / 0.9907 AUC
  • Chronological LSTM (Leak-Free): 76.74% Accuracy / 0.7097 Macro F1

ACADEMIC SYNTHESIS

Core Research Findings & Critical Insights

1. The Target Leakage Trap

Descriptions containing 'DOMESTIC' and NCRB source columns sharing 76.6% target count yield illusory 90%+ accuracy. Real future forecasting demands rigorous pre-incident feature audits.

2. Mandatory Chronological Splitting

Random train/test splits interpolate between concurrent events. Locking 2025 (Chicago) and 2013–2014 (NCRB) test sets provides genuine out-of-distribution evaluation.

3. Class Imbalance & Metric Deception

With 18.4% domestic prevalence, predicting all non-domestic yields 81.6% accuracy but 0% recall. Tuning threshold to 0.47 captures 87.18% of domestic abuse altercations.

4. Tabular ML vs Sequence DL Divide

XGBoost dominates static incident triage (0.9152 AUC) with fast training. For multi-year district forecasting, LSTM sequence modeling (+0.0125 F1 gain) outperforms static models.

STRATEGIC SYNTHESIS

Conclusion & Ethical Guardrails

1. Research Contributions

Exposed and purged structural target leakage, proved that domain-engineered risk priors boost discrimination from 0.5593 to 0.9152 ROC-AUC, and demonstrated that Isotonic Regression reduces probability error to 0.47% while maintaining demographic parity across 22 districts.

2. Strict Rejection of Predictive Policing

This framework is built strictly for retrospective analysis and emergency dispatcher triage support. It is NOT intended for predictive policing, proactive surveillance, or individual risk scoring.
